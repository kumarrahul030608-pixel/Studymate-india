Module 1 — Digital Logic Circuits

1. Digital Computer and Binary Information

A digital computer represents information using discrete values, usually binary 0 and 1. Input data is encoded, stored, processed by arithmetic/logic circuits and controlled through instructions. The major functional units are input unit, output unit, memory, arithmetic logic unit (ALU) and control unit.

2. Number Systems and Conversions

Common bases are binary (2), octal (8), decimal (10) and hexadecimal (16). In positional notation, the value is the sum of digit × base raised to its position.

(1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11₁₀
(2F)₁₆ = 2×16 + 15 = 47₁₀

Decimal-to-binary conversion for an integer repeatedly divides by 2 and reads remainders upward. Binary-to-octal groups bits in threes; binary-to-hexadecimal groups bits in fours.

3. Logic Gates

AND gives 1 only when all inputs are 1. OR gives 1 when at least one input is 1. NOT complements its input. NAND and NOR are universal gates. XOR gives 1 when inputs differ; XNOR gives 1 when inputs are equal.

4. Boolean Algebra Laws

Identity: A+0=A, A·1=A. Null: A+1=1, A·0=0. Idempotent: A+A=A, A·A=A. Complement: A+A′=1, A·A′=0. Absorption: A+AB=A and A(A+B)=A.

De Morgan's laws: (A+B)′=A′B′ and (AB)′=A′+B′. These laws are used to simplify expressions and transform circuits.

Example: F=A+AB = A(1+B)=A. The expression needs only A after simplification.

5. SOP, POS and Logic Simplification

Sum of Products (SOP) is an OR of product terms. Product of Sums (POS) is an AND of sum terms. A truth table can be converted into canonical SOP using minterms for output 1 or canonical POS using maxterms for output 0. Karnaugh maps (K-maps) provide a graphical method for minimizing Boolean expressions by grouping adjacent 1s (SOP) or 0s (POS).

6. Combinational Circuits

In a combinational circuit, output depends only on current input. There is no stored previous state.

Half Adder: S=A⊕B, C=AB.
Full Adder: S=A⊕B⊕Cin; Cout=AB+ACin+BCin.
Half Subtractor: D=A⊕B, Borrow=A′B.
Multiplexer: selects one of many inputs using select lines.
Demultiplexer: routes one input to a selected output.
Encoder: converts one active input among many to a coded output.
Decoder: converts coded input into one of many output lines.
Comparator: determines equality and relative magnitude of binary numbers.

7. Sequential Circuits and Flip-Flops

Sequential circuits have memory; output depends on present inputs and previous state. Latches are generally level-sensitive while flip-flops are commonly edge-triggered.

Flip-FlopBasic behavior
SRSet or reset; a particular input combination is invalid in the basic implementation.
JKLike SR with the J=K=1 condition causing toggle.
DNext state follows D at the active clock event.
TT=0 holds; T=1 toggles.

8. Registers and Counters

Registers store groups of bits. Shift registers are classified as SISO, SIPO, PISO and PIPO. Counters sequence through states and may be asynchronous (ripple) or synchronous. Mod-n counters have n states.

9. Signed Binary and Error Control

Signed numbers can use sign-magnitude, one's complement and two's complement. Two's complement is formed by inverting every bit and adding 1.

0101 → invert 1010 → +1 = 1011

Parity adds a redundant bit for simple error detection. Hamming coding uses parity positions to detect/locate certain single-bit errors.

Practice: Draw truth tables, simplify Boolean expressions, solve K-map problems, design half/full adders and subtractors, explain multiplexers/decoders, and compare SR/JK/D/T flip-flops.

Module 2 — Register Transfer & Micro-operations

1. Register Transfer Language (RTL)

RTL describes data transfers and micro-operations between registers. R2 ← R1 means the contents of R1 are transferred to R2 at the required control event; R1 itself is unchanged.

2. Arithmetic Micro-operations

Arithmetic micro-operations include add, subtract, increment and decrement. They are implemented using registers and arithmetic circuits such as adders.

R3 ← R1 + R2
R1 ← R1 + 1
R2 ← R2 − 1

3. Logic Micro-operations

Bitwise AND, OR, XOR and complement can be performed on register contents. They are useful for masking, setting, clearing and toggling bits.

4. Shift Micro-operations

Logical shifts move bits and fill the vacated position with zero. Arithmetic right shift preserves the sign bit. Circular shifts rotate bits around the register.

5. Bus Organization

A bus is a shared path connecting registers and functional units. Multiplexers or tri-state buffers select the active source. A shared bus must be controlled so multiple sources do not drive it simultaneously.

6. ALU and Shifter

The ALU performs arithmetic and logical operations. A shifter moves bits left/right. Together they form important parts of the CPU datapath and are controlled by control signals.

Module 3 — Basic Computer Organization & Design

1. Instruction Cycle

The CPU repeatedly performs fetch, decode and execute. During fetch, the instruction address is obtained using the program counter; the instruction is loaded into the instruction register. Decode identifies the operation and operands. Execute performs the required micro-operations.

Typical idea: AR ← PC → memory read → IR ← instruction → decode → execute

3. Instruction Format

An instruction contains an opcode identifying the operation and fields specifying operands, registers or addresses. Different architectures use different formats and numbers of operands.

4. Control Unit

The control unit coordinates datapath operations by generating timing and control signals. A hardwired control unit uses fixed logic; a microprogrammed control unit uses control memory containing microinstructions.

Module 4 — Central Processing Unit

1. CPU Organization

The CPU contains registers, ALU, control unit and interconnection paths. Registers provide fast storage; the ALU performs operations; the control unit directs the sequence of operations.

2. Stack Organization

A stack follows LIFO. PUSH adds an item; POP removes the top item. The stack pointer identifies the top. Stacks support expression evaluation, procedure calls, local data and interrupt handling.

3. Addressing Modes

Immediate: operand value is in instruction.
Direct: address field gives effective address.
Indirect: address field refers to a location containing the effective address.
Register: operand is in a register.
Register indirect: register contains operand address.
Indexed: base address plus index gives effective address.
Relative: displacement is combined with a reference such as PC.

4. Interrupts

An interrupt requests CPU attention for an event. The processor saves necessary state, transfers control to an interrupt service routine and later resumes the interrupted program. Interrupts can be hardware or software generated and may be maskable or non-maskable depending on the architecture.

5. RISC and CISC

RISC emphasizes a relatively small, regular instruction set and efficient pipelining. CISC generally provides a richer set of instructions and addressing capabilities, potentially reducing instructions per program but increasing implementation complexity. Modern processors often combine ideas from both approaches.

Module 5 — Memory Organization

1. Memory Hierarchy

Memory is organized from fastest/smallest to slower/larger levels: registers → cache → main memory → secondary storage. Higher levels are closer to CPU and generally have lower access time but higher cost per bit.

2. SRAM and DRAM

SRAM uses stable storage cells and does not require refresh; it is fast and commonly used for cache. DRAM stores charge in cells that require periodic refresh; it is denser and commonly used for main memory.

3. ROM Family

ROM retains information without ordinary power. PROM is programmable once; EPROM can be erased and reprogrammed; EEPROM can be electrically erased/reprogrammed. Flash is a widely used electrically erasable non-volatile memory technology.

4. Cache Memory and Locality

Cache stores copies of recently/frequently used memory blocks. Temporal locality means recently used data is likely to be used again. Spatial locality means nearby addresses are likely to be accessed.

Hit: requested block found in cache. Miss: block must be obtained from a lower level. Hit rate = hits / total accesses.

5. Cache Mapping

Direct mapping: each memory block maps to exactly one cache line. Fully associative: a block can occupy any line. Set associative: a block maps to a set and can occupy one of several lines within that set.

6. Virtual Memory and Paging

Virtual memory provides a logical address space larger than physical RAM. In paging, logical memory is divided into pages and physical memory into frames. A page table maps pages to frames. A page fault occurs when the referenced page is not resident in RAM and must be fetched from storage.

7. Page Replacement

When there is no free frame, an existing page may be replaced. FIFO removes the oldest loaded page; LRU removes the least recently used page. Replacement algorithms are evaluated by page-fault behavior for a given reference string.

8. Memory Numericals

Be prepared for effective-address calculations, cache mapping, tag/index/offset bits, hit/miss calculations, page-table address translation and page-replacement reference strings.
