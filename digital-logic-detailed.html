Module 1 — Digital Logic Circuits

Digital Computer

A digital computer works with discrete binary information. Input data is encoded, processed by arithmetic and logic circuits, stored in memory and controlled through instruction sequences. The basic functional units are input, output, memory, ALU and control unit.

Logic Gates

AND produces 1 only when all inputs are 1. OR produces 1 when at least one input is 1. NOT complements its input. NAND and NOR are universal gates. XOR produces 1 when inputs differ; XNOR produces 1 when inputs are equal.

Boolean Algebra

Boolean algebra simplifies logic expressions. Important laws: A+0=A, A·1=A; A+1=1, A·0=0; A+A=A; A·A=A; A+A′=1; A·A′=0; A+AB=A; A(A+B)=A.

De Morgan: (A+B)′=A′B′ and (AB)′=A′+B′. These laws are frequently used to convert and minimize circuits.

Combinational Circuits

In combinational circuits, output depends only on current inputs. A half adder adds two bits: S=A⊕B, C=AB. A full adder adds A, B and carry-in: S=A⊕B⊕Cin, Cout=AB+BCin+ACin.

Half subtractor: Difference=A⊕B and Borrow=A′B. A multiplexer selects one input from many using select lines. A demultiplexer sends one input to one selected output. Encoders convert 2ⁿ input lines into n coded outputs; decoders perform the reverse.

Sequential Circuits

Sequential circuits have memory, so output depends on current input and previous state. Latches are level-sensitive; flip-flops are storage elements commonly triggered by a clock edge. SR, JK, D and T flip-flops are standard. D captures input data; T toggles; JK can toggle when J=K=1.

Registers and Counters

Registers store multiple bits. Shift registers can be serial-in/serial-out, serial-in/parallel-out, parallel-in/serial-out or parallel-in/parallel-out. Counters move through a sequence of states and may be asynchronous (ripple) or synchronous.

Number Representation

Binary arithmetic is fundamental. Signed values can use sign-magnitude, one's complement and two's complement. Two's complement is formed by complementing all bits and adding 1.

Two's complement of 0101 → invert 1010 → +1 = 1011

Fixed-point reserves a fixed number of fractional bits. Floating-point represents a number using sign, exponent and significand. Overflow means the result is outside the representable range.

Error Detection and Correction

Parity adds a redundant bit for simple error detection. Hamming codes place parity bits at power-of-two positions and can locate certain single-bit errors. Error-control methods are important in reliable data storage and transmission.

Module 2 — Register Transfer & Micro-operations

RTL

Register Transfer Language represents data movement between registers. R2 ← R1 means contents of R1 are copied to R2. Transfers happen when the required control signal is active.

Micro-operations

Register-transfer micro-operations move data. Arithmetic micro-operations include addition, subtraction, increment and decrement. Logic micro-operations include AND, OR, XOR and complement. Shift micro-operations include logical, circular and arithmetic shifts.

R3 ← R1 + R2
R4 ← shl R4
R5 ← R5 + 1

Bus Organization

A bus provides a shared communication path between registers and functional units. Multiplexers or tri-state buffers can control which source drives the bus. Only one source should drive a shared bus at a time.

Arithmetic Logic Shift Unit

An ALU performs arithmetic and logical operations, while a shifter performs bit movement. An arithmetic-logic-shift unit combines these functions to form a basic CPU datapath.

Module 3 — Basic Computer Organization & Design

Instruction Cycle

The CPU repeatedly fetches an instruction from memory, decodes it and executes it. The program counter identifies the next instruction. The instruction register holds the current instruction. Control logic generates signals for the required micro-operations.

Registers

  • PC — Program Counter: next instruction address.
  • IR — Instruction Register: current instruction.
  • AR/MAR — Address Register: memory address.
  • DR/MDR — Data Register: memory data.
  • AC — Accumulator: arithmetic/logic operand/result.
  • TR — Temporary Register: temporary internal data.

Instruction Codes

An instruction generally contains an opcode and operand/address information. Memory-reference instructions use an address field to locate data. Instruction decoding determines which operation and micro-operations are required.

Module 4 — Central Processing Unit

Register Organization

CPU registers provide very fast storage for operands, addresses, instructions and intermediate results. A common datapath connects registers through buses to the ALU.

Stack Organization

A stack follows LIFO. PUSH adds data to the top; POP removes the top element. A stack pointer identifies the current top. Stacks are used for subroutine calls, expression evaluation and temporary data.

Addressing Modes

Immediate: operand is inside instruction. Direct: address field is operand address. Indirect: address field points to a location containing operand address. Register: operand is in a register. Register indirect: register holds operand address. Indexed: address plus index gives effective address. Relative: displacement is added to a reference such as PC.

Interrupts

An interrupt lets a CPU temporarily suspend normal execution and service an event. After saving required state and executing the interrupt service routine, normal execution resumes. Interrupts reduce the need for constant polling.

RISC

RISC processors emphasize a relatively small set of simple instructions, regular instruction formats and efficient pipelining. This can simplify hardware and improve instruction throughput.

Module 5 — Memory Organization

Memory Hierarchy

Registers are fastest and smallest, followed by cache, main memory and secondary storage. Moving down the hierarchy generally increases capacity and decreases cost per bit but increases access time.

RAM and ROM

SRAM is fast and does not need refresh, making it suitable for cache. DRAM is denser and requires refresh, making it common for main memory. ROM retains its contents without power and has variants such as PROM, EPROM and EEPROM.

Cache

Cache keeps recently/frequently used memory blocks near the CPU. A hit is served from cache; a miss requires access to a lower memory level. Locality of reference makes caching effective.

Cache Mapping

Direct mapping: each memory block maps to one cache line. Fully associative: block can be placed in any line. Set associative: block maps to a set and can occupy one of several lines.

Virtual Memory

Virtual memory gives processes a large logical address space. Paging divides logical memory into pages and physical memory into frames. A page fault occurs when a required page is not currently in RAM.

Replacement Algorithms

When a cache/page must be replaced, policies such as FIFO and LRU choose a victim. LRU removes the least recently used item, while FIFO removes the oldest item.
