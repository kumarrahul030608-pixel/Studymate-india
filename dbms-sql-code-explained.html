1. CREATE TABLE — Structure Banana

CREATE TABLE Student ( roll_no INT PRIMARY KEY, name VARCHAR(50) NOT NULL, major VARCHAR(30), gpa DECIMAL(3,2) );
CREATE TABLE Student — Student naam ki table banata hai.
roll_no INT PRIMARY KEY — roll number integer hoga aur duplicate/null primary-key values allowed nahi hoti.
name VARCHAR(50) NOT NULL — name text hoga, maximum 50 characters; value dena compulsory hai.
major VARCHAR(30) — branch/major ke liye text column.
gpa DECIMAL(3,2) — decimal value store karne ke liye.
Exam point: DDL commands database structure define karte hain. CREATE, ALTER aur DROP common DDL commands hain.

2. INSERT — Data Enter Karna

INSERT INTO Student (roll_no, name, major, gpa) VALUES (10, 'Rahul', 'CSE', 8.50); INSERT INTO Student VALUES (11, 'Aman', 'IT', 7.80);

First form me columns explicitly likhe gaye hain, isliye safer hai. VALUES ke andar values same order me deni hoti hain.

Common error: text values ko quotes me likho: 'Rahul'. Numeric values normally quotes ke bina likhe jaate hain.

3. SELECT — Data Retrieve Karna

SELECT name, gpa FROM Student WHERE gpa >= 8 ORDER BY gpa DESC;
  1. SELECT name, gpa — sirf required columns show karega.
  2. FROM Student — Student table se data lega.
  3. WHERE gpa >= 8 — sirf GPA 8 ya usse zyada wali rows.
  4. ORDER BY gpa DESC — highest GPA se lowest GPA tak sort.
Important: WHERE rows ko filter karta hai; ORDER BY result ko sort karta hai. ASC ascending aur DESC descending hota hai.

4. DISTINCT, BETWEEN, IN, LIKE

SELECT DISTINCT major FROM Student; SELECT * FROM Student WHERE gpa BETWEEN 7 AND 9; SELECT * FROM Student WHERE major IN ('CSE','IT'); SELECT * FROM Student WHERE name LIKE 'R%';

DISTINCT duplicate result values remove karta hai. BETWEEN range check karta hai. IN multiple possible values match karta hai. LIKE 'R%' R se start hone wale names find karta hai; % zero ya more characters represent karta hai.

5. Aggregate Functions + GROUP BY + HAVING

SELECT major, COUNT(*) AS total_students, AVG(gpa) AS average_gpa, MAX(gpa) AS highest_gpa, MIN(gpa) AS lowest_gpa FROM Student GROUP BY major HAVING AVG(gpa) >= 7;

COUNT rows count karta hai, AVG average, MAX maximum, MIN minimum aur SUM total nikalta hai.

WHERE vs HAVING: WHERE grouping se pehle individual rows filter karta hai. HAVING grouping ke baad groups filter karta hai. Isliye aggregate condition jaise AVG(gpa) ko HAVING me likhna natural hai.

6. JOINS — Multiple Tables Ko Connect Karna

SELECT s.name, d.dept_name FROM Student s INNER JOIN Department d ON s.dept_id = d.dept_id;

s aur d aliases hain. ON condition batati hai ki dono tables ka relation kaise match hoga.

JoinMeaning
INNER JOINSirf matching rows.
LEFT JOINLeft table ki sab rows + matching right rows.
RIGHT JOINRight table ki sab rows + matching left rows.
FULL OUTER JOINDono sides ki rows; DBMS support vary kar sakta hai.
SELECT s.name, d.dept_name FROM Student s LEFT JOIN Department d ON s.dept_id = d.dept_id;

LEFT JOIN ka advantage: jis student ka department match nahi karta, student row phir bhi result me rahegi; department columns NULL ho sakte hain.

7. SUBQUERY — Query Ke Andar Query

SELECT name, gpa FROM Student WHERE gpa > ( SELECT AVG(gpa) FROM Student );
Step 1: inner query SELECT AVG(gpa) average GPA calculate karti hai.
Step 2: outer query har student ka GPA us average se compare karti hai.
Step 3: sirf above-average students return hote hain.

8. UPDATE and DELETE

UPDATE Student SET gpa = 9.00 WHERE roll_no = 10; DELETE FROM Student WHERE roll_no = 11;
Golden rule: UPDATE/DELETE me WHERE carefully check karo. WHERE hata diya to table ki every row update/delete ho sakti hai.

9. ALTER TABLE

ALTER TABLE Student ADD email VARCHAR(100); ALTER TABLE Student DROP COLUMN email;

ALTER existing table structure change karta hai. Exact syntax DBMS ke according thoda vary kar sakta hai.

10. TCL — COMMIT, ROLLBACK, SAVEPOINT

START TRANSACTION; UPDATE Student SET gpa = 9.10 WHERE roll_no = 10; SAVEPOINT s1; UPDATE Student SET gpa = 8.90 WHERE roll_no = 11; ROLLBACK TO s1; COMMIT;

COMMIT changes permanently confirm karta hai. ROLLBACK uncommitted changes undo karta hai. SAVEPOINT transaction ke andar intermediate point banata hai.

Exam explanation: Transaction me multiple related operations ko logical unit ke roop me execute kiya ja sakta hai. Failure ki situation me rollback consistency maintain karne me help karta hai.

11. Common SQL Mistakes

1. String ko quotes ke bina likhna.
2. UPDATE/DELETE me WHERE bhool jana.
3. GROUP BY me required non-aggregated columns ko properly handle na karna.
4. JOIN me wrong ON condition dena.
5. NULL ko = NULL se compare karna; NULL ke liye IS NULL / IS NOT NULL use hota hai.
6. SQL clause order confuse karna. Common order: SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY.
