Chapter 1 — Java Fundamentals

1.1 What is Java?

Java is a strongly typed, class-based programming language. A Java source file is compiled into bytecode. The Java Virtual Machine executes that bytecode, which is why the same compiled program can run on different operating systems that provide a compatible JVM.

Exam definition: Java is a high-level, object-oriented, class-based language designed to support portable and robust application development.

1.2 JDK, JRE and JVM

TermMeaningRole
JDKJava Development KitTools to develop and compile programs
JREJava Runtime EnvironmentRuntime libraries + JVM for running applications
JVMJava Virtual MachineLoads, verifies and executes bytecode

Flow: Main.java → javac → Main.class → JVM → execution.

1.3 First Program — Line by Line

public class Main { public static void main(String[] args) { System.out.println("Hello World"); } }
  1. public class Main declares a class named Main.
  2. main is the conventional entry point for a Java application.
  3. public allows the runtime to access the method.
  4. static means the method belongs to the class, so an object is not required to invoke it.
  5. void means it returns no value.
  6. System.out.println prints text followed by a new line.

1.4 Class and Object

A class is a blueprint; an object is a runtime instance. Fields represent state and methods represent behavior.

class Student { String name; int marks; void display() { System.out.println(name + " " + marks); } } class Main { public static void main(String[] args) { Student s = new Student(); s.name = "Rahul"; s.marks = 85; s.display(); } }
Explanation: Student defines the blueprint. new Student() creates an object. s.name and s.marks access instance fields. s.display() calls the object's method.

1.5 Data Types, Variables and Casting

Primitive types are byte, short, int, long, float, double, char and boolean. A variable may be local, instance or static. Widening conversion is normally automatic; narrowing requires an explicit cast.

int a = 10; double b = a; // widening int c = (int)12.8; // narrowing: c becomes 12

Chapter 2 — Operators, Decision Statements, Loops and Arrays

2.1 Operators

Arithmetic: + − * / %. Relational: < > <= >= == !=. Logical: && || !. Assignment: = += -= *= /=. Unary: ++ --. Conditional: ?: . Bitwise operators work directly on integer bits.

2.2 if-else — Explained

int marks = 78; if (marks >= 90) { System.out.println("A"); } else if (marks >= 60) { System.out.println("B"); } else { System.out.println("C"); }

The conditions are checked from top to bottom. For 78, the first condition is false and the second is true, so the output is B.

2.3 Loops

for (int i = 1; i <= 5; i++) { System.out.println(i); }

Initialization runs once, the condition is checked before each iteration, the body executes, and the update runs after the body. Use while when the number of iterations depends mainly on a condition. Use do-while when the body must execute at least once.

2.4 Array Sum and Maximum

int[] a = {10, 20, 7, 40, 15}; int sum = 0; int max = a[0]; for (int x : a) { sum += x; if (x > max) max = x; } System.out.println("Sum = " + sum); System.out.println("Max = " + max);

Logic: start sum at 0; start max with the first element; visit every element; add it to sum; replace max whenever a larger value is found. This is O(n) time.

2.5 Two-Dimensional Array and Matrix Addition

int[][] a={{1,2},{3,4}}; int[][] b={{5,6},{7,8}}; int[][] c=new int[2][2]; for(int i=0;i<2;i++){ for(int j=0;j<2;j++){ c[i][j]=a[i][j]+b[i][j]; } }

Both matrices must have the same dimensions for addition. The outer loop selects the row and the inner loop selects the column.

Chapter 3 — Methods, Constructors, this, super and Strings

3.1 Method Structure

static int add(int a, int b) { return a + b; }

static is the modifier, int is the return type, add is the method name, and a,b are parameters. The return statement sends the result back to the caller.

3.2 Method Overloading

Same method name + different parameter list. Changing only return type is not enough. Example: add(int,int) and add(double,double). The compiler selects the appropriate overload.

3.3 Constructors

class Student { String name; int age; Student() { this("Unknown", 0); } Student(String name, int age) { this.name = name; this.age = age; } }

The constructor runs when an object is created. this.name=name distinguishes the field from the parameter. this(...) calls another constructor in the same class.

3.4 this and super

this refers to the current object. super refers to the immediate superclass. super() can call a superclass constructor.

3.5 Strings

String objects are immutable. Important methods include length(), charAt(), substring(), equals(), compareTo(), contains() and replace(). Use StringBuilder for many repeated changes.

Chapter 4 — Four Pillars of OOP

4.1 Encapsulation

Keep data and behavior together and restrict direct access. A common approach is private fields plus public methods.

class Account { private double balance; public void deposit(double amount) { if (amount > 0) balance += amount; } public double getBalance() { return balance; } }

4.2 Inheritance and Overriding

class Animal { void sound() { System.out.println("Animal"); } } class Dog extends Animal { @Override void sound() { System.out.println("Bark"); } }

Dog extends Animal creates inheritance. @Override documents that the subclass replaces an inherited method implementation.

4.3 Runtime Polymorphism

Animal a = new Dog(); a.sound(); // Bark

The reference type is Animal but the actual object is Dog. The overridden instance method is selected at runtime.

4.4 Abstraction and Interfaces

interface Printable { void print(); } class Report implements Printable { public void print() { System.out.println("Report"); } }

An interface specifies a contract. A class implementing it provides the required behavior. Abstract classes can combine abstract and concrete methods.

Chapter 5 — Exception Handling

5.1 try-catch-finally

try { int result = 10 / 0; System.out.println(result); } catch (ArithmeticException e) { System.out.println("Cannot divide by zero"); } finally { System.out.println("Done"); }
  1. Risky code goes inside try.
  2. If division by zero occurs, an ArithmeticException is thrown.
  3. The matching catch handles it.
  4. finally runs for cleanup logic whether an exception occurs or not in normal control flow.

5.2 throw and throws

throw explicitly throws an exception object. throws declares that a method may pass an exception to its caller. Checked exceptions generally require handling or declaration.

5.3 Custom Exception

class AgeException extends Exception { AgeException(String msg) { super(msg); } } class Main { static void checkAge(int age) throws AgeException { if (age < 18) throw new AgeException("Not eligible"); } }

6.2 ArrayList and HashMap

import java.util.*; ArrayList names = new ArrayList<>(); names.add("Rahul"); names.add("Aman"); for (String n : names) System.out.println(n); HashMap students = new HashMap<>(); students.put(10, "Rahul"); System.out.println(students.get(10));

add inserts into the list. put associates a key with a value. get retrieves a value using its key.

Chapter 7 — Input/Output, Files, Serialization and Threads

7.1 Scanner Input

import java.util.Scanner; class Main { public static void main(String[] args) { Scanner sc = new Scanner(System.in); int a = sc.nextInt(); int b = sc.nextInt(); System.out.println("Sum = " + (a+b)); } }

If input is 10 20, Scanner reads 10 into a and 20 into b, then output is Sum = 30. Online compilers provide these values through standard input.

7.2 File Streams

Byte streams handle binary data; character streams handle text. Buffered streams can improve efficiency. Modern Java code should use try-with-resources so files are closed automatically.

7.3 Multithreading

class Task implements Runnable { public void run() { System.out.println("Task running"); } } class Main { public static void main(String[] args) { Thread t = new Thread(new Task()); t.start(); } }

Runnable defines the work. Thread executes it. start() starts a new thread; calling run() directly does not create a new thread.
