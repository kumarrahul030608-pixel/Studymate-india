Chapter 1 — Java Fundamentals

1.1 Programming Paradigms

A programming paradigm is a way of organizing a solution. Procedure-oriented programming focuses on functions and sequence of operations. Object-oriented programming organizes software around objects containing state and behavior. Java is primarily class-based and object-oriented.

1.2 Java Features

Java is strongly typed, class-based and portable through bytecode. Commonly discussed features include platform independence, automatic memory management, exception handling, multithreading, security features and a large standard library.

1.3 JDK, JRE and JVM

JDK provides development tools such as the compiler. JRE provides the runtime environment and libraries. JVM loads, verifies and executes bytecode.

Flow: .java source → javac compiler → .class bytecode → JVM → execution.

1.4 Class and Object

A class is a blueprint containing fields and methods. An object is an instance created at runtime. Every object has identity, state and behavior.

class Student { String name; int marks; void display() { System.out.println(name + " " + marks); } } class Main { public static void main(String[] args) { Student s = new Student(); s.name = "Rahul"; s.marks = 85; s.display(); } }

1.5 Data Types and Variables

Primitive types are byte, short, int, long, float, double, char and boolean. Variables may be local, instance or static. Reference variables refer to objects rather than storing the object's complete state directly.

Chapter 2 — Operators, Decisions, Loops and Arrays

2.1 Operators

Arithmetic operators perform calculations; relational operators compare values; logical operators combine conditions; assignment operators update variables; unary operators change one operand; the conditional operator provides a compact expression.

2.2 Decision Statements

int marks = 78; if (marks >= 90) System.out.println("A"); else if (marks >= 60) System.out.println("B"); else System.out.println("C");

Use switch when one expression is matched against multiple cases. Always use break or the intended fall-through behavior deliberately.

2.3 Loops

for is convenient when initialization, condition and update are known. while checks before each iteration. do-while runs the body at least once. break exits; continue skips the rest of the current iteration.

2.4 Arrays

An array stores a fixed number of same-type elements. Indexing starts at zero.

int[] a = {10,20,30,40,50}; int sum = 0; for (int x : a) sum += x; System.out.println("Sum = " + sum);

2.5 Two-Dimensional Arrays

int[][] a={{1,2},{3,4}}; int[][] b={{5,6},{7,8}}; int[][] c=new int[2][2]; for(int i=0;i<2;i++) for(int j=0;j<2;j++) c[i][j]=a[i][j]+b[i][j];

Practice matrix addition, transpose and multiplication. For multiplication, the number of columns of the first matrix must equal the number of rows of the second.

Chapter 3 — Methods, Constructors, Strings and Packages

3.1 Methods

A method has a name, parameter list and return type. Static methods belong to the class; instance methods operate on an object. Parameters receive values when the method is called.

static int add(int a,int b){ return a+b; }

3.2 Method Overloading

Overloading means multiple methods with the same name but different parameter lists. Return type alone cannot distinguish overloads. Overload resolution happens at compile time.

3.3 Constructors

A constructor has the same name as its class and no return type. It initializes objects. Constructors may be no-argument or parameterized and can be overloaded.

class Student { String name; int age; Student(){ this("Unknown",0); } Student(String name,int age){ this.name=name; this.age=age; } }

3.4 this and super

this refers to the current object and can call another constructor using this(). super refers to the superclass and can call superclass constructors or access inherited members.

3.5 Strings

String is immutable. Important methods include length, charAt, substring, equals, compareTo, contains and replace. For repeated modifications, StringBuilder is usually more suitable.

3.6 Packages and Access

Packages organize related classes. Access modifiers control visibility: public is broadly accessible, private is class-only, protected supports package access plus subclass access, and default access is package-private.

Chapter 4 — Inheritance, Polymorphism, Abstraction and Interfaces

4.1 Inheritance

Inheritance creates an is-a relationship. A subclass extends a superclass and can reuse or specialize inherited behavior. Java does not allow multiple inheritance of classes, but a class can implement multiple interfaces.

class Animal { void sound(){System.out.println("Animal");} } class Dog extends Animal { @Override void sound(){System.out.println("Bark");} }

4.2 Overriding and Runtime Polymorphism

Animal a = new Dog(); a.sound(); // Bark

The actual object determines which overridden instance method executes at runtime.

4.3 Encapsulation

Encapsulation combines data and methods and controls access. A common pattern is private fields with public getters/setters and validation logic.

4.4 Abstraction

Abstraction exposes essential behavior while hiding implementation details. Abstract classes can contain abstract and concrete methods. Interfaces define contracts that implementing classes fulfill.

4.5 Interface Example

interface Printable { void print(); } class Report implements Printable { public void print(){System.out.println("Report");} }

Chapter 5 — Exception Handling and Collections

5.1 Exceptions

An exception represents an abnormal condition that interrupts normal execution. Use try-catch to handle exceptions, finally for cleanup logic, throw to explicitly raise an exception and throws to declare that a method may propagate an exception.

try { int result = 10 / 0; } catch (ArithmeticException e) { System.out.println("Cannot divide by zero"); } finally { System.out.println("Done"); }

5.2 Checked and Unchecked Exceptions

Checked exceptions are checked by the compiler and generally must be handled or declared. Runtime exceptions are unchecked. Good exception handling should provide meaningful recovery rather than hiding programming errors.

5.3 Collections Framework

List stores an ordered sequence and permits duplicates. Set represents unique elements. Map stores key-value pairs. Common classes include ArrayList, LinkedList, HashSet, TreeSet and HashMap.

import java.util.*; ArrayList names=new ArrayList<>(); names.add("Rahul"); names.add("Aman"); for(String n:names) System.out.println(n); HashMap m=new HashMap<>(); m.put(10,"Rahul"); System.out.println(m.get(10));

Chapter 6 — Input/Output, Files and Multithreading

6.1 Console Input

import java.util.Scanner; class Main { public static void main(String[] args){ Scanner sc=new Scanner(System.in); int a=sc.nextInt(); int b=sc.nextInt(); System.out.println(a+b); } }

In an online compiler, values for Scanner are supplied through standard input/stdin.

6.2 File I/O

Byte streams are suitable for binary data. Character streams are intended for text. Buffered streams can improve I/O efficiency.

6.3 Serialization

Serialization converts an object into a byte representation that can be stored or transmitted. A serializable class commonly implements Serializable.

6.4 Multithreading

A thread is a path of execution. Threads can be created using Thread or Runnable. Synchronization is used to protect shared mutable state from race conditions.

class Task implements Runnable { public void run(){ System.out.println("Task running"); } } class Main { public static void main(String[] args){ new Thread(new Task()).start(); } }
