Module 1 — Digital Logic Circuits

Digital Computers: Process binary data using logic, memory, control and arithmetic units.
Logic Gates: AND, OR, NOT, NAND, NOR, XOR and XNOR. NAND and NOR are universal gates.
Boolean Algebra: Identity, null, complement, idempotent, absorption and De Morgan laws simplify logic expressions.
Combinational Circuits: Half adder, full adder, half subtractor, full subtractor, multiplexers, demultiplexers, encoders and decoders.
Sequential Circuits: Latches and flip-flops store state. Common types: SR, JK, D and T.
Registers: Shift registers move stored bits left/right; counters advance through defined states.
Memory: RAM is read/write volatile memory; ROM is non-volatile. Memory hierarchy balances speed, cost and capacity.
Arithmetic: Binary addition/subtraction, signed numbers, overflow, fixed-point and floating-point representation.
Error Codes: Error detection/correction techniques add redundant bits to identify or correct transmission/storage errors.

Module 2 — Register Transfer & Micro-operations

Register Transfer Language describes movement of data between registers. Micro-operations include register transfer, arithmetic, logic and shift operations.
Bus organization provides a shared path for transferring data among registers. Three-state buffers help control bus access.
Arithmetic micro-operations include add, subtract, increment and decrement. Logic micro-operations include AND, OR, XOR and complement.
Shift micro-operations include logical, circular and arithmetic shifts.
Example RTL: R2 ← R1 R3 ← R1 + R2 R4 ← shl R4

Module 3 — Basic Computer Organization & Design

Instruction Codes: Binary patterns specify operation and operand/address information.
Computer Registers: PC stores next instruction address; IR stores current instruction; AC is an accumulator; AR/MAR stores addresses; DR/MDR stores data.
Memory Reference Instructions: Use an address field to access memory. Instruction execution proceeds through fetch, decode and execute.
Accumulator Logic: The accumulator participates in arithmetic and logic operations.

Module 4 — Central Processing Unit

Register Organization: CPU registers hold operands, addresses, instructions and intermediate results.
Stack Organization: Uses LIFO order. PUSH inserts an item; POP removes the top item.
Instruction Formats: Define opcode and operand/address fields.
Addressing Modes: Immediate, direct, indirect, register, register-indirect, indexed and relative.
Interrupts: Allow the CPU to respond to events without continuously polling. RISC uses a smaller, simpler instruction set.

Module 5 — Memory Organization

Memory Hierarchy: Registers → cache → main memory → secondary storage, moving from fastest/smallest to slower/larger.
RAM & ROM: SRAM is fast and commonly used for cache; DRAM is denser and used for main memory. ROM variants retain data without power.
Cache Mapping: Direct, associative and set-associative mapping determine where memory blocks may be placed in cache.
Virtual Memory: Extends apparent memory using secondary storage and address translation.
Replacement: FIFO, LRU and other policies choose which cache/page to replace.
