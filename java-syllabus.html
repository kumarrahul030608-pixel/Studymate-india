Module 1 — Procedure-Oriented & Object-Oriented Programming

Procedure-Oriented Programming

Procedure-oriented programming organizes a program around functions or procedures. Data is often passed between functions. It works well for smaller algorithmic tasks but large systems can become harder to maintain because data and operations are less tightly organized.

Object-Oriented Programming

OOP organizes software around objects that combine state (data) and behavior (methods). Its major benefits are modularity, code reuse, maintainability, extensibility and easier modeling of real-world entities.

Four Pillars of OOP

  • Encapsulation: Bundling data and methods and controlling access.
  • Abstraction: Showing essential behavior while hiding implementation details.
  • Inheritance: Creating a new class from an existing class for reuse.
  • Polymorphism: One interface/name can represent different implementations.

Java Program Structure

A Java source file normally contains classes and methods. Execution begins from public static void main(String[] args). The source is compiled into bytecode, which the JVM executes.

JDK, JRE and JVM

JDK contains tools needed to develop Java programs. JRE provides the runtime environment. JVM loads, verifies and executes Java bytecode and provides platform independence.

class Student { private String name; Student(String name) { this.name = name; } void display() { System.out.println("Name: " + name); } public static void main(String[] args) { Student s = new Student("Rahul"); s.display(); } }

Module 2 — Data Types, Control Statements & Arrays

Data Types

Java has eight primitive types: byte, short, int, long, float, double, char and boolean. Reference types include classes, interfaces, arrays and enums. Variables must have a declared type.

Control Statements

Selection: if, if-else, nested if and switch. Iteration: for, while and do-while. Jump: break, continue and return.

Arrays

An array stores a fixed number of values of the same type. Indexing starts at 0. A two-dimensional array can represent a matrix. Use array.length to get its size.

Module 3 — Functions, Overloading, References & Constructors

Methods

A method is a named block of code that performs a task. A method can accept parameters and return a value. Static methods belong to the class, while instance methods operate on objects.

Method Overloading

Overloading means multiple methods have the same name but different parameter lists. The compiler chooses the applicable method at compile time.

class Calculator { int add(int a, int b) { return a + b; } int add(int a, int b, int c) { return a + b + c; } double add(double a, double b) { return a + b; } }

Constructors

A constructor initializes an object and has the same name as its class. It has no return type. Constructors can be overloaded. If no constructor is declared, Java may provide a default constructor.

Reference Variables

A reference variable stores a reference to an object. The this keyword refers to the current object; super refers to the superclass portion of an object.

Garbage Collection

Java automatically reclaims memory occupied by objects that are no longer reachable. Programmers do not explicitly free ordinary objects as in C/C++.

Module 4 — Inheritance & Collections

Inheritance

Inheritance allows a subclass to reuse accessible members of a superclass. Common forms are single, multilevel and hierarchical inheritance. Java does not support multiple inheritance of classes.

class Animal { void sound() { System.out.println("Animal sound"); } } class Dog extends Animal { @Override void sound() { System.out.println("Bark"); } } public class Demo { public static void main(String[] args) { Animal a = new Dog(); a.sound(); } }

Overriding & Runtime Polymorphism

When a subclass provides a method with the same signature as the superclass, it overrides that method. With a superclass reference referring to a subclass object, the overridden method is selected at runtime.

Abstract Classes & Interfaces

An abstract class can contain abstract and concrete methods. An interface defines a contract that implementing classes fulfill. A class can implement multiple interfaces.

Collections Framework

ArrayList provides a resizable list; LinkedList is useful for linked-list operations; HashSet stores unique elements; TreeSet maintains sorted unique elements; HashMap stores key-value pairs.

import java.util.*; public class CollectionDemo { public static void main(String[] args) { ArrayList names = new ArrayList<>(); names.add("Rahul"); names.add("Aman"); names.add("Neha"); for(String name : names) System.out.println(name); } }

Module 5 — Applets, Graphics & Input/Output

Applet Concepts

Applets are legacy Java programs designed to run inside a browser/applet viewer. Typical lifecycle methods taught academically are init(), start(), paint(), stop() and destroy(). Modern browsers and current Java releases no longer support browser applets, so this part is mainly historical syllabus material.

Java I/O

Byte streams handle binary data, while character streams handle text. FileInputStream/FileOutputStream work with bytes; FileReader/FileWriter work with characters; buffered classes improve efficiency.

import java.io.*; public class FileRead { public static void main(String[] args) throws IOException { try(BufferedReader br = new BufferedReader(new FileReader("data.txt"))) { String line; while((line = br.readLine()) != null) { System.out.println(line); } } } }

Serialization

Serialization converts an object's state into a byte stream so it can be stored or transferred. A serializable class implements Serializable. Deserialization reconstructs the object state.
