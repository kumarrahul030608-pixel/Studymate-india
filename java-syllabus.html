Module 1 — Procedure-Oriented Programming & Object-Oriented Programming

1. Programming Paradigms

A programming paradigm is a style of organizing and solving problems using a programming language. In procedure-oriented programming, the program is divided into procedures/functions and the main focus is on the sequence of operations. In object-oriented programming, the program is organized around objects that contain state and behavior.

Why OOP? Large programs need modularity, reuse, controlled access to data and easy maintenance. OOP addresses these requirements through classes, objects, encapsulation, abstraction, inheritance and polymorphism.

2. Class and Object

A class is a blueprint that defines fields and methods. An object is a runtime instance of a class. Each object has state, behavior and identity. Objects are created using new.

class Student { String name; int marks; void display() { System.out.println(name + " " + marks); } } class Main { public static void main(String[] args) { Student s = new Student(); s.name = "Rahul"; s.marks = 85; s.display(); } }

3. Four Pillars of OOP

Encapsulation
Combining data and methods in a class and restricting direct access using private/protected/public access control.
Abstraction
Showing essential operations while hiding implementation details, commonly through abstract classes and interfaces.
Inheritance
Deriving a new class from an existing class to reuse and specialize behavior.
Polymorphism
The same operation can behave differently depending on the object or method signature. Overloading is compile-time; overriding enables runtime polymorphism.

4. Java Features

Java is class-based, object-oriented, strongly typed and designed for portability through bytecode. Commonly described features include platform independence, automatic memory management, exception handling, multithreading, security mechanisms and a rich standard library.

5. JDK, JRE and JVM

JDK is the development kit containing tools such as the compiler. JRE is the runtime environment and libraries needed to run Java applications. JVM loads, verifies and executes bytecode. The basic flow is source (.java) → compiler → bytecode (.class) → JVM → machine execution.

6. Java Program Structure and Tokens

A Java program can contain package declarations, imports, classes, fields, constructors and methods. Tokens include identifiers, keywords, literals, operators and separators. Java identifiers are case-sensitive.

public class Main { public static void main(String[] args) { System.out.println("Hello World"); } }

Module 2 — Data Types, Variables, Operators, Control Statements & Arrays

1. Data Types

Java has eight primitive types: byte, short, int, long, float, double, char, boolean. Reference types include classes, arrays, interfaces, enums and other object references. Primitive variables store values directly; reference variables refer to objects.

Important: int is commonly used for whole-number calculations. Use long for larger integer ranges and double for common floating-point calculations.

2. Variables and Type Casting

Variables may be local, instance or static. Widening conversion can happen automatically when moving to a compatible wider type. Narrowing conversion requires an explicit cast and can lose information.

int a = 10; double x = a; // widening int b = (int) 12.8; // narrowing: b becomes 12

3. Operators

Arithmetic: +, -, *, /, %. Relational: <, >, <=, >=, ==, !=. Logical: &&, ||, !. Assignment: =, +=, -=, etc. Unary: ++, --. Conditional: ?: . Bitwise operators work at bit level.

4. Decision Statements

if executes a block conditionally; if-else chooses between alternatives; nested conditions handle multiple levels. switch is useful when one expression is compared against multiple cases.

int marks = 78; if (marks >= 90) System.out.println("A"); else if (marks >= 60) System.out.println("B"); else System.out.println("C");

5. Loops

for is convenient when the iteration structure is known, while checks before each iteration, and do-while executes the body at least once. break exits a loop; continue skips to the next iteration.

6. Arrays

An array is a fixed-size indexed collection of values of the same type. The first index is 0. A one-dimensional array represents a sequence; a two-dimensional array can represent a matrix.

int[] a = {10, 20, 30, 40, 50}; for (int i = 0; i < a.length; i++) { System.out.println(a[i]); } int[][] matrix = {{1,2},{3,4}}; System.out.println(matrix[1][0]); // 3

7. Common Array Problems

Practice sum/average, maximum/minimum, reverse, linear search, sorting, duplicate detection, frequency counting, matrix addition, transpose and multiplication. When explaining a program, state the algorithm, input, loop logic and complexity.

Module 3 — Methods, References, Constructors & Memory

1. Methods

A method is a named block that performs a specific operation. Its declaration can contain access modifier, static/instance modifier, return type, method name and parameter list. void means it returns no value.

static int add(int a, int b) { return a + b; } public static void main(String[] args) { System.out.println(add(10, 20)); }

2. Method Overloading

Method overloading allows the same method name with different parameter lists. Changing only the return type does not create a valid overload. The compiler resolves an overload at compile time.

3. Constructors

A constructor initializes a newly created object. It has the class name and no return type. Constructors can be no-argument or parameterized and can be overloaded. this() can call another constructor in the same class.

class Student { String name; int age; Student() { this("Unknown", 0); } Student(String name, int age) { this.name = name; this.age = age; } }

4. this and super

this refers to the current object and can resolve field/parameter name conflicts. super refers to the superclass and can access superclass members or call a superclass constructor.

5. Passing Values and References

Java is pass-by-value. For an object parameter, the value passed is the reference value; the method can modify the referenced object's state, but reassigning the parameter does not change the caller's reference.

6. Garbage Collection

Java automatically manages memory. Objects that are no longer reachable become eligible for garbage collection. The exact time of garbage collection is controlled by the runtime, not by the programmer.

7. Strings

String objects are immutable. Common operations include length(), charAt(), substring(), equals(), compareTo() and toUpperCase(). Use StringBuilder for efficient repeated modifications.

Module 4 — Inheritance, Interfaces, Polymorphism & Collections

1. Inheritance

Inheritance creates an is-a relationship. Java supports single, multilevel and hierarchical inheritance of classes. Multiple inheritance of classes is not supported, but multiple interfaces can be implemented.

class Animal { void sound() { System.out.println("Animal sound"); } } class Dog extends Animal { @Override void sound() { System.out.println("Bark"); } }

2. Method Overriding

Overriding occurs when a subclass provides a compatible implementation of an inherited instance method. The method signature must match according to Java's overriding rules. @Override helps the compiler catch mistakes.

3. Runtime Polymorphism

Animal a = new Dog(); a.sound(); // Bark

The reference type is Animal, but the object is Dog. The overridden instance method is selected according to the actual object at runtime.

4. Abstract Classes

An abstract class cannot be instantiated directly. It may contain abstract methods and concrete methods. A subclass generally must implement inherited abstract methods unless the subclass is also abstract.

5. Interfaces

An interface defines a contract. A class uses implements to fulfill that contract and may implement multiple interfaces. Modern Java interfaces may also contain default and static methods.

interface Printable { void print(); } class Report implements Printable { public void print() { System.out.println("Report"); } }

6. Exception Handling

An exception is an abnormal condition that interrupts normal execution. Use try, catch, finally, throw and throws to handle or declare exceptional conditions. Checked exceptions are checked by the compiler; unchecked exceptions include runtime exceptions.

try { int result = 10 / 0; System.out.println(result); } catch (ArithmeticException e) { System.out.println("Cannot divide by zero"); } finally { System.out.println("Done"); }

7. Collections Framework

List maintains an ordered sequence and can contain duplicates. Set represents unique elements. Map stores key-value associations. Common implementations are ArrayList, LinkedList, HashSet, TreeSet and HashMap.

import java.util.*; ArrayList<String> names = new ArrayList<>(); names.add("Rahul"); names.add("Aman"); for (String name : names) System.out.println(name); HashMap<Integer,String> m = new HashMap<>(); m.put(10, "Rahul"); System.out.println(m.get(10));

Module 5 — Input/Output, Files, Threads & Legacy Applets

1. Console Input

Scanner can read primitive values and strings from standard input. In online compilers, standard input is normally supplied through the compiler's stdin/input box.

import java.util.Scanner; class Main { public static void main(String[] args) { Scanner sc = new Scanner(System.in); int a = sc.nextInt(); int b = sc.nextInt(); System.out.println("Sum = " + (a + b)); } }
Online compiler tip: If nextInt() throws NoSuchElementException, the program was expecting input but stdin was empty or did not contain enough values.

2. Byte and Character Streams

Byte streams such as FileInputStream/FileOutputStream are suited to binary data. Character streams such as FileReader/FileWriter are designed for text. Buffered streams reduce frequent direct I/O operations.

import java.io.*; class FileRead { public static void main(String[] args) throws IOException { try (BufferedReader br = new BufferedReader(new FileReader("data.txt"))) { String line; while ((line = br.readLine()) != null) System.out.println(line); } } }

3. Serialization

Serialization converts an object's state to a byte stream for storage or transfer. A class can implement Serializable. Deserialization reconstructs the stored object state. Serializable classes should be designed carefully when data compatibility and security matter.

4. Multithreading

A thread is an independent path of execution within a process. Java supports threads through the Thread class and Runnable/Callable abstractions. Basic lifecycle ideas include creation, runnable/running execution and termination. Synchronization is used to protect shared mutable state.

class Task extends Thread { public void run() { System.out.println("Task running"); } } class Main { public static void main(String[] args) { new Task().start(); } }

5. Applets

Java applets are legacy browser-oriented technology. Academic syllabi may cover init(), start(), paint(), stop() and destroy(). Modern browsers and current Java environments do not support browser applets, so this topic is mainly historical.
