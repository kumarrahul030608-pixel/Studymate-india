Module 1 — OOP Introduction

Object-oriented programming models software using objects and classes. Main benefits include reuse, modularity, abstraction, maintainability and extensibility.
Java: Java source is compiled to bytecode executed by the JVM. JDK provides development tools, JRE provides runtime components, and JVM executes bytecode.
Classes define state and behavior; objects are instances of classes. Access modifiers control visibility.
class Student { String name; Student(String name) { this.name = name; } } Student s = new Student("Rahul");

Module 2 — Data Types, Control Statements & Arrays

Primitive types: byte, short, int, long, float, double, char, boolean. Reference types include classes, arrays and interfaces.
Control statements: if/else, switch, for, while, do-while, break, continue and return.
Arrays: Store multiple values of one type. Access with zero-based indexes. Multidimensional arrays are arrays of arrays.
public class ArraySum { public static void main(String[] args) { int[] a = {10,20,30,40}; int sum = 0; for(int x : a) sum += x; System.out.println("Sum = " + sum); } }

Module 3 — Functions, Overloading & Constructors

Methods contain reusable behavior. Method overloading means same method name with different parameter lists. Java passes arguments by value.
Constructors initialize objects and have the same name as the class. A constructor has no return type.
Encapsulation combines data and methods; inheritance enables reuse; polymorphism allows one interface with different implementations.
class Calculator { int add(int a,int b){ return a+b; } double add(double a,double b){ return a+b; } }

Module 4 — Inheritance & Collections

Inheritance lets a subclass acquire accessible members of a superclass. Java supports single, multilevel and hierarchical class inheritance; multiple inheritance of classes is not supported.
Keywords: extends, super, final. Method overriding enables runtime polymorphism. Abstract classes define incomplete abstractions. Interfaces define contracts and support multiple type inheritance.
Common collections: ArrayList, LinkedList, HashSet, TreeSet, HashMap and TreeMap.

Module 5 — Basic Applets & I/O

The syllabus includes applet concepts, HTML applet tags, applet life cycle, parameters, graphics and applet input/output. Modern Java no longer uses applets in current mainstream JDKs, so these are primarily legacy academic concepts.
I/O streams include byte streams and character streams. Buffered streams improve efficient reading/writing. Serialization converts object state to a byte stream.
import java.io.*; public class FileDemo { public static void main(String[] args) throws Exception { try(BufferedReader br = new BufferedReader(new FileReader("data.txt"))) { String line; while((line = br.readLine()) != null) System.out.println(line); } } }
