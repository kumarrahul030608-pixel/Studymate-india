1. Database

A database is an organized collection of related data that can be easily accessed, managed and updated.

2. DBMS

DBMS is software used to create, store, retrieve, update and manage databases.

Advantages

  • Data security
  • Reduced redundancy
  • Data sharing
  • Backup and recovery

3. Data Models

  • Relational model
  • ER model
  • Hierarchical model
  • Network model
  • Object-oriented model

4. SQL

DDL: CREATE, ALTER, DROP

DML: INSERT, UPDATE, DELETE

DQL: SELECT

5. Data Independence

Ability to change the schema at one level without changing the schema at the next higher level. Types: physical and logical data independence.
