Basics

Java is an object-oriented, class-based programming language. A Java program is compiled into bytecode and runs on the JVM.

OOP Concepts

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

Arrays

An array stores multiple values of the same type. Example: int[] a = {10,20,30};

Exception Handling

Use try, catch, finally, throw and throws to handle exceptional situations.
