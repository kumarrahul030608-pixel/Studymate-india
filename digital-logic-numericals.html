1. Number System — Detailed

Binary uses base 2, octal base 8, decimal base 10 and hexadecimal base 16. In positional notation each digit is multiplied by a power of the base.

Numerical 1: Convert (101101)₂ to decimal.

= 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰
= 32 + 0 + 8 + 4 + 0 + 1
= 45₁₀

Numerical 2: Convert 45₁₀ to binary.

45÷2 = 22 remainder 1
22÷2 = 11 remainder 0
11÷2 = 5 remainder 1
5÷2 = 2 remainder 1
2÷2 = 1 remainder 0
1÷2 = 0 remainder 1
Read remainders bottom-to-top: 101101₂.

Numerical 3: Convert (2F)₁₆ to decimal.

F = 15. Therefore 2×16¹ + 15×16⁰ = 32+15 = 47₁₀.

2. Binary Arithmetic & Two's Complement

Numerical: Find 2's complement of 010110.

Step 1: Invert bits → 101001.
Step 2: Add 1 → 101010.
Answer = 101010.

Memory trick: 2's complement = 1's complement + 1. It is widely used to represent negative integers in binary arithmetic.

3. Boolean Algebra — Simplification

Use identity, complement, absorption and De Morgan laws to reduce logic expressions and therefore reduce circuit complexity.

Numerical 1: Simplify F = A + AB.

F = A(1+B)
Since 1+B = 1,
F = A×1 = A.

Numerical 2: Simplify F = A + A'B.

Use X + X'Y = X + Y.
Therefore F = A+B.

De Morgan example: (A+B)' = A'B'. For a product, (AB)' = A'+B'.

4. K-Map — How to Solve

Karnaugh Map is a graphical method for minimizing Boolean expressions. For SOP, place 1s for minterms and group adjacent 1,2,4,8... cells. Make groups as large as possible and use wrap-around adjacency where valid.

Step 1: Write minterms from the question.
Step 2: Fill 1s in the correct K-map cells.
Step 3: Make largest possible groups.
Step 4: Write common variables of each group.
Example: F(A,B,C)=Σ(1,3,5,7). All listed minterms have C=1, so the minimized expression is F=C.

5. Adders and Subtractors

Half Adder: Sum = A⊕B, Carry = AB
Full Adder: Sum = A⊕B⊕Cin
Cout = AB + ACin + BCin
Numerical: Full adder A=1, B=1, Cin=0.

Sum = 1⊕1⊕0 = 0.
Carry = (1)(1)+(1)(0)+(1)(0) = 1.
So output = Sum 0, Carry 1.

Half subtractor A=0, B=1: Difference = 0⊕1 = 1; Borrow = A'B = 1×1 = 1.

6. Flip-Flops — Concept + Questions

Flip-flops are storage elements used in sequential circuits. SR provides set/reset, JK removes the basic SR invalid condition and toggles when J=K=1, D stores the input value, and T toggles when T=1.

JK Numerical: If J=1 and K=1, next state is the complement of present state. If present Q=0, next Q=1; if present Q=1, next Q=0.
D Flip-Flop: If D=1 at the active clock event, next Q=1. If D=0, next Q=0.

7. CPU and Addressing Mode Numericals

Effective address example — direct addressing: If address field = 2500 and mode is direct, EA = 2500.
Indexed example: Base/address field = 2000 and index register = 150. EA = 2000 + 150 = 2150.

Immediate mode is different: the instruction contains the operand value itself, so there may be no separate memory lookup for the operand.

8. Cache Mapping Numerical

Suppose main memory has 16 blocks and cache has 4 lines. In direct mapping:

Step 1: Number of cache lines = 4 = 2², so index needs 2 bits.
Step 2: Main-memory block number maps using block number mod 4.
Step 3: Blocks 0,4,8,12 map to line 0; 1,5,9,13 to line 1; 2,6,10,14 to line 2; 3,7,11,15 to line 3.
Hit rate = Hits / Total accesses
Miss rate = 1 − Hit rate

9. Paging and Page Replacement

Address translation: If page size = 1024 bytes and logical address = 2500, page number = floor(2500/1024) = 2 and offset = 2500 − 2048 = 452. The page table is then used to find the physical frame for page 2.
FIFO example: For 3 frames and reference string 1,2,3,4, the first three pages fill the frames. On reference 4, the oldest page (1) is replaced, giving frames 4,2,3 depending on frame representation.
